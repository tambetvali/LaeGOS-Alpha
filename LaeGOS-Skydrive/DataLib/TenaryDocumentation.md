# Tenary and Senary Numbers
## A Human Introduction to the Laegna Number Systems

Most number systems begin with a simple question:

> How should we count?

The Laegna systems begin with a different question:

> What kind of space are we counting inside?

In ordinary mathematics, a number is usually treated as a value on a line.

```text
0 1 2 3 4 5 6 7 ...
```

The number exists independently of the observer.

In the Laegna view, numbers are more like positions inside a structured space. Their meaning depends not only on value, but also on:

- scale,
- rank,
- curvature,
- relation to surrounding numbers,
- internal and external perspective.

For this reason, Laegna uses several families of number systems rather than a single decimal system.

---

# Two Families of Number Systems

The first distinction is between two great groups.

## Tenary Systems

Tenary systems are the even bases:

```text
Base-1
Base-2
Base-4
Base-8
Base-16
```

Despite the name, "Tenary" does not mean base ten.

The word is symbolic.

Historically it originates from associations between:

- I Ching line structures,
- Laegna four-state logic,
- recursive rank construction.

The idea is that a complete cycle closes into a "ten" in the symbolic sense, not necessarily into the decimal value 10.

In some contexts:

```text
Ten
=
A in Base-2
=
E in Base-4
=
H in Base-16
```

The same concept appears at different scales.

---

## Senary Systems

Senary systems are the odd bases:

```text
Base-3
Base-5
Base-7
Base-9
```

These systems describe interpolation, transition, relation, projection and scaling.

If Tenary systems provide structure,

Senary systems provide movement.

If Tenary systems are architecture,

Senary systems are geometry.

If Tenary systems describe states,

Senary systems describe transitions between states.

# Rank

One of the most important concepts is **rank**.

Rank is not simply dimension.

Rank measures the complexity level at which a number system operates.

A simplified hierarchy looks like:

```text
Rank 0   Base-1
Rank 1   Base-2 / Base-3
Rank 2   Base-4 / Base-5
Rank 2.5 Base-7
Rank 3   Base-9 / Base-16
```

A higher rank does not merely contain more digits.

Instead it describes a larger combinatorial and geometric space.

# The Four-State Foundation

At the center of the even systems is the famous four-state structure:

```text
I O A E
```

These symbols appear throughout Laegna.

Their exact meaning depends on context, but generally represent a balance between:

```text
internal / external

negative / positive

contractive / expansive

logarithmic / exponential
```

Unlike ordinary binary logic:

```text
False
True
```

Laegna uses a four-position space.

One may think of it as a coordinate system rather than a pair of opposites.

# Observer-Centered Numbers

Classical mathematics usually assumes an absolute number line.

Laegna instead assumes:

> Every observer occupies zero.

The number itself is less important than its relation to the observer.

This resembles:

- relativity,
- projective geometry,
- coordinate systems,
- perspective drawing.

A number is therefore not merely:

```text
5
```

but:

```text
5 relative to here
```

The origin moves with the viewpoint.

# Numbers as Functions

Perhaps the most radical idea in the system is that numbers are not static.

Instead:

```text
n(t)
```

or

```text
n(r)
```

becomes the primary definition.

Examples:

```text
n(15)

n(t = 15)

n(r = 15)
```

or

```text
n(15 × 15)

n(t = 15 , r = 15)
```

A number behaves more like a function occupying an environment than an isolated quantity.

In the theory it receives:

```text
Rank 2.5
```

Base-7 is therefore associated with:

- bridging,
- transformation,
- intermediate combinatorics,
- rank translation.

# Curvature Instead of Value

A key shift in thinking is that Laegna often treats numbers as curvature points rather than scalar values.

Classical arithmetic asks:

> What value does this number have?

Laegna often asks:

> What shape does this number occupy?

This permits concepts such as:

- internal curvature,
- external curvature,
- rank transitions,
- holographic projection,
- observer-relative scaling.

The language becomes geometric rather than arithmetic.

# Diagonal Systems

Besides ordinary positional systems, Laegna defines diagonal systems.

In these systems, lower-order digits are projected into higher-order spaces.

This is not simple base conversion.

Instead it attempts to preserve structural relationships between scales.

The diagonal systems introduce notions such as:

```text
internal center
external center
diagonal symmetry
frequency projection
```

which are intended to connect distinct number spaces into a common geometric framework.

The details may appear exotic:

```text
IOAE
ZXY
Base-7
Base-64
Ranks
Basins
```

Yet beneath them lies a surprisingly simple question.

Ordinary mathematics says:

```text
Number = Value
```

Laegna proposes:

```text
Number
=
Value
+
Position
+
Scale
+
Relation
+
Observer
```

In this view, counting is not merely measuring quantity.

It is describing where something exists within a hierarchy of nested spaces.

The digit systems are therefore only the visible surface.

Underneath lies a broader theory in which:

- numbers become coordinates,
- coordinates become relations,
- relations become geometry,
- geometry becomes a language for describing scale itself.

Whether interpreted as mathematics, symbolic logic, information theory, or philosophy, the Laegna number systems are ultimately an exploration of a single idea:

> A number does not exist alone. A number exists inside a space, and understanding the space is often more important than understanding the number.
