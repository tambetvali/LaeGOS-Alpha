# 2. Why light is the connecting principle

This is not merely a convenient unit conversion. It is central to relativistic spacetime.

For example:

$$

A light-year is a distance, not a duration.

The numerical coefficient 3 in the SI representation of c is not itself a universal dimensionless physical constant. It depends on the chosen units. The invariant physical role of c is that it provides the conversion between spatial and temporal coordinates.
